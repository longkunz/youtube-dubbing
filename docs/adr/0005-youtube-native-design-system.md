# 5. YouTube-Native Ambient Design System (SUPERSEDED)

We initially considered conforming strictly to YouTube's ambient dark theme. This has been replaced by [ADR-0006](0006-hyper-fantastic-hud-design-system.md) in favor of an unapologetically hyper-modern, futuristic, sci-fi HUD aesthetic for controls, while maintaining gentle native styling for the subtitle text overlay.
